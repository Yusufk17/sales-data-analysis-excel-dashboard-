
# Sales Data Analysis Excel Dashboard

A Sales Data Analysis Dashboard created using Microsoft Excel to analyze sales performance and identify key business insights.

## Project Overview

This project analyzes sales data using Microsoft Excel and presents the results through an interactive dashboard.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Dashboard

## Key Performance Indicators

- Total Sales: ₹164,700
- Total Profit: ₹18,800
- Total Quantity: 16
- Total Orders: 10

## Analysis

The dashboard provides analysis of:

- Sales by Date
- Sales by City
- Sales by Product
- Sales by Category

## Dashboard

The dashboard presents key sales metrics and visual insights in a simple and easy-to-understand format.
